# Spilno — дизайн: итоги и передача в разработку (05.11.2026)

Дополняет «Прошлое обсуждение». Всё ниже — состояние на момент перехода к коду.

## Где лежит дизайн
- Полотно Claude Design «Spilno — карта і дизайн» (artifact 3YgJ96rqMvA7UbPSDw4vHU): карта, 15 экранов, стиль; интерактивный прототип.
- Figma: https://www.figma.com/design/Pk5klZ9grzKxjf8ci5wqjl — 5 страниц: 1·Карта, 2·Основні екрани, 3·Перший запуск, 4·Монобанк, 5·Стиль. Слои плоские (без компонентов и переменных).
## Карта приложения
- Вход: Онбординг (3 слайда) → Вхід (email-код, Apple, Google) → Сім’я (створити / приєднатися за кодом).
- Таб-бар: Огляд · Операції · ＋ Нова витрата (FAB) · Розрахунки · Ще.
- Огляд → Аналітика (етап 2); баннер «N нових операцій з mono» → черга «Розібрати».
- Операції (фильтр усі/спільні/мої) → Деталі операції → Редагувати поділ.
- Нова витрата: тип витрата/дохід/переказ, сума, категорія, рахунок, дата, коментар, хто платив, «Спільна» → Поділ: порівну / частками / сумами.
- Розрахунки: баланс каждого с последнего расчёта, минимальные переводы, «Отримав» / «Нагадати» / «Пробачити», історія.
- Ще: профиль; Сім’я (учасники й ролі, запросити — код/посилання); Гроші (рахунки, категорії, монобанк, правила спільних); Додаток (Face ID, сповіщення, валюта й мова); Вийти.
- Вне навигации: push → Деталі; вебхук mono → «Розібрати»; посилання-запрошення → Вхід → сім’я; замок биометрией при запуске.
- Монобанк (етап 2): токен (api.monobank.ua, QR, вставить) → рахунки (вкл/выкл, режим новых операций: на розгляд / спільні / особисті; глубина истории: місяць / 3 / рік, ~1 мин на месяц на счёт) → імпорт (прогресс по месяцам, «Розібрати N»).
## Стиль «Спільний стіл»
- Шрифт Manrope (кириллица, tabular-nums). Шкала: сумма 36/42·800, заголовок экрана 28/34·800, секция 17/24·800, основной 15/20·700/500, подпись 12/16·600, таб 11·600–700.
- Цвета: фон #F5F6F8, карточка #FFFFFF, текст #15171C, вторичный #5A6070, линии #E3E6EC, акцент #2550D9, акцент мягкий #E8EEFF, «вам винні» #1E44C0, «ви винні»/холд #A3420D, доход #1E7A4A.
- Участники: пары фон/буква #DCE5FF/#1B3A99, #FFE3CF/#8A3A0A, #DDF1E3/#1E6B3D, #F0E8FF/#5B2BB5, #FFF1CC/#7A5200 (те же пары для иконок категорий).
- Радиусы: 20 карточки, 14 плитки, 12 кнопки; отступы 4·8·12·16·20; иконки контур ~1.9–2, 24px; цели касания ≥44px.
- Деньги: «1 248,60 ₴» — неразрывный пробел в тысячах, запятая, знак после; «−» для расходов, «+» для дохода, перевод без знака серым.
## Допущения, которые ещё не решены
- Баланс считается с последнего взаиморасчёта, а не помесячно.
- Подтверждение расчёта — кнопка «Отримав» у получателя, без отдельного экрана.
- Решено 10.11.2026: отдельной очереди «Розібрати» нет, импорт из mono всегда личный, см. `docs/decisions.md`.
- Формат кода-приглашения.
- Apple-вход: нужен в iOS, если есть Google-вход.
